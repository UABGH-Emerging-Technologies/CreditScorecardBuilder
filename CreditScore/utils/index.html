DefinitionMatcher

Match feature names to phenotype definitions.

Methods

  • get_definition(self, feature)
  • Returns a single string containing the matched phenotype's return_columns entries relevant to feature. Uses multiple strategies: 1) Exact return_column key match 2) Exact phenotype name match 3) Exact composite "phenotype|return_key" match 4) Token-sort fuzzy match across all candidates If no match above threshold, returns "No definition available".
